# Drop model files here

Put downloaded car, traffic, tree and building models (.glb, .gltf zips or .fbx zips) in this folder,
any names, any sizes up to 100 MB each. They get sorted, renamed and compressed for the game later.

Licences: Quaternius, Kenney and Kay Lousberg models are CC0 (no credit needed). Models marked
**credit** are most likely CC-BY (Poly by Google and most individual Sketchfab/Poly Pizza authors), so
they need the author's name in the game's credits if they ship.
